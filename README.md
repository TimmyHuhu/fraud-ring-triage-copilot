# Fraud Ring Triage Copilot

Track 02 — Fraud Watch

Fraud Ring Triage Copilot is a multi-agent investigation dashboard that helps fraud analysts detect hidden fraud rings, rank suspicious cases, recommend next actions, and generate downloadable case reports.

## Product Brief

See the full product brief: [product_brief.pdf](./product_brief.pdf)

## Agents

1. Pattern Finder — detects suspicious transaction patterns.
2. Risk Ranker — scores and prioritizes cases.
3. Action Recommender — recommends escalation, watchlist, or dismissal.
4. Analyst Report Writer — generates a downloadable investigation report.
